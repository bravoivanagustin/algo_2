# Algoritmos y Estructuras de Datos II (Algo 2)

Material de la materia Algoritmos y Estructuras de Datos II. Todo el código es Java (`package aed`).

| Carpeta | Contenido |
|---|---|
| `talleres/` | Un taller por carpeta (`taller_1` … `taller_5`) |
| `tp/` | Trabajo práctico |
| `otros/` | Código suelto que no es de un taller (`main.cpp`) |

## Talleres

- `taller_1`: funciones básicas.
- `taller_2`: cobertura de tests y debugging.
- `taller_3`: agenda de recordatorios (fechas, horarios, arreglo redimensionable).
- `taller_4`: lista doblemente enlazada.
- `taller_5`: árbol binario de búsqueda (ABB).

## TP

Sistema de inscripciones tipo SIU (`SistemaSIU.java`): carreras, materias, alumnos y docentes, indexados con un `Trie` propio.

> Los `.java` mantienen mayúsculas porque Java exige que el archivo se llame igual que su clase.
